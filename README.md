# Pauta Digital Experience — micrositio independiente

Sitio de Pauta Digital Experience, mantenido en un repositorio separado de carlosguerraoficial.com.

## Publicación

URL prevista al habilitar GitHub Pages: https://carlosguerra88.github.io/pautadigitalexperience/

En Settings > Pages seleccionar Deploy from a branch, main, /(root).

## Archivo pendiente

**Debe subirse a la raíz del repositorio `pauta-digital-experience.mp4` (12,6 MB).** El conector de GitHub no pudo transferir el video por límite de tamaño. Sin él, la landing carga, pero el video no se reproducirá. Está dentro del paquete ZIP original y del ZIP del micrositio.

En GitHub: Add file > Upload files, seleccionar solamente `pauta-digital-experience.mp4` y confirmar el commit.
