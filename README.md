# Pauta Digital Experience — micrositio independiente

Micrositio estático, con diseño y contenido del ZIP original. Este paquete está adaptado para un **repositorio distinto** de `carlosguerraoficial.com`.

## Dirección prevista

`https://carlosguerra88.github.io/pautadigitalexperience/`

La URL quedará disponible solo **después de crear el repositorio y activar GitHub Pages**. El nombre del repositorio debe ser exactamente `pautadigitalexperience`.

## Publicación mediante GitHub web

1. En la cuenta **CarlosGuerra88**, crea un repositorio público nuevo llamado **pautadigitalexperience** (`https://github.com/new`). No uses `CarlosGuerra88/carlosguerraoficial.com`.
2. Descomprime este ZIP en tu equipo.
3. En el nuevo repositorio, usa **Add file → Upload files** y sube los archivos descomprimidos de esta carpeta directamente a la raíz (no subas el ZIP en sí ni una carpeta contenedora). Incluye `index.html`, imágenes, MP4, `.nojekyll` y `sitemap.xml`.
4. En **Settings → Pages**, en **Build and deployment → Source**, selecciona **Deploy from a branch**; en **Branch** usa `main` y `/(root)` y guarda.
5. Comprueba `https://carlosguerra88.github.io/pautadigitalexperience/` y que se reproduzca el video y funcionen los botones de WhatsApp.

## Independencia

- No hay archivo `CNAME`, ni enlaces a `carlosguerraoficial.com`.
- No modifiques archivos de la web principal ni agregues navegación cruzada.
- El banner de marca conserva a Carlos Guerra como presentador, pero el encabezado regresa a este micrositio.
- SEO (canonical, Open Graph, JSON-LD, video) apunta a la URL GitHub Pages del micrositio.
- `sitemap.xml` describe únicamente la URL del micrositio. El archivo `robots.txt` original no se copia, porque no controla un proyecto que vive bajo una ruta del dominio `github.io`.

## Funciones conservadas

- Video de presentación en MP4 (archivo local), póster y fotografías.
- Conversión a WhatsApp y medición con Meta Pixel que venían configuradas en el archivo original.
- La prevención de avance de video y desbloqueo posterior del precio, tal como estaban configuradas.
- Preventa hasta el **14-oct-2026 23:59** (Ecuador), cambio automático a precio regular al día siguiente.
- Tipografías externas Google Fonts.

## Antes de campañas

Verifica el video, los teléfonos de WhatsApp, el Pixel y los precios publicados. Las fechas y valores provienen del archivo entregado. GitHub Pages publica de forma pública: evita subir datos confidenciales.

## Importante

Este archivo no crea por sí solo el repositorio, no habilita GitHub Pages y no constituye confirmación de publicación. Una vez subido, verifica la URL.
